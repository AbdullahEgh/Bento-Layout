Windows 0.3.12 shows every projected slot on the target monitor while dragging, with a stronger outline for the incoming window. Moving between monitors also previews changed slots on the source monitor. Preview panels remain pass-through and hide together when the drag ends or is cancelled.

The existing Windows Snap control is now in Workspace under Desktop space as “Disable Windows Snap.” It temporarily lets Bento handle snapping while active and restores the prior Windows setting when Bento turns off or quits.

The Windows updater identity and asset names are unchanged. The included Mac ZIP remains the published macOS 0.2.40 asset. Validation evidence is recorded in RELEASE-RESULT.md.
